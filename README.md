# Element Remove 🧹

**Element Remove** là một extension trình duyệt nhỏ gọn, mạnh mẽ giúp bạn dọn dẹp các thành phần không mong muốn (quảng cáo, popup che màn hình, sidebar rườm rà, v.v.) trên bất kỳ trang web nào chỉ bằng vài cú nhấp chuột.

## 🚀 Tính năng nổi bật

* **Xóa theo thời gian thực:** Kích hoạt chế độ xóa và chỉ cần di chuột vào phần tử cần loại bỏ.
* **Giao diện trực quan:** Hiển thị viền đánh dấu (highlight) rõ ràng để bạn biết chính xác phần tử nào đang chuẩn bị bị xóa.
* **Không lưu trữ rác:** Thao tác xóa diễn ra trực tiếp trên DOM của trang hiện tại, giúp trang web sạch sẽ ngay lập tức.
* **Nhẹ và nhanh:** Không làm chậm trình duyệt, không thu thập dữ liệu người dùng.
